# Bat Listener — Ultrasonic Audio Translator (Python)

A desktop application that takes recorded bat echolocation sounds (ultrasonic, 20–120 kHz) and makes them audible to humans through frequency shifting. Built as a complete Python rewrite of the [original HTML bat listener](../bat-listener-e4b/) generated by E4B, with clean, commented, modular code for review and extension.

## Why Python?

The original was a single 1055-line HTML file generated in one shot by an LLM. While impressive, it had several bugs (undefined variables, a broken `HeterodyneNode` class, missing functions, DOM references to non-existent elements). This rewrite:

- **Separates concerns** into 7 focused modules with clear interfaces
- **Uses real DSP** (scipy filters, numpy FFT) instead of Web Audio API approximations
- **Has working implementations** of all three frequency-shift methods
- **Is fully commented** for code review and educational use
- **Runs offline** as a native desktop app (no browser needed)

## The 7 Modules (from the gap analysis)

| Module | File | What It Does |
|--------|------|-------------|
| 1. Audio Input & Decoding | `audio_engine.py` | WAV file loading, live microphone, transport controls |
| 2. Frequency Shift Engine | `audio_engine.py` | Time expansion, heterodyne, frequency division (3 methods) |
| 3. Real-Time Spectrogram | `spectrogram.py` | Scrolling FFT display, color map, dual-panel, freq labels |
| 4. Bat Species ID Guide | `species_guide.py` | 12-species database, peak frequency matching, click-to-tune |
| 5. Audio Filters | `audio_engine.py` | Highpass, lowpass, bandpass, noise gate, volume boost |
| 6. Recording & Export | `recorder.py` | Record shifted audio, export WAV, export spectrogram PNG |
| 7. Canvas UI & Layout | `ui_canvas.py` | Full pygame-drawn UI: buttons, sliders, toggles, panels |

Plus: `main.py` (entry point + main loop), `settings.py` (JSON config persistence).

## Frequency Shift Methods

| Method | How It Works | Preserves Harmonics | Real-Time | Best For |
|--------|-------------|---------------------|-----------|----------|
| Time Expansion | Slowed playback (1/factor speed) | Yes (musical transposition) | No | Detailed analysis |
| Heterodyne | Mix with local oscillator sine | No (difference tone only) | Yes | Real-time field monitoring |
| Frequency Division | Integer playback slowdown | Yes (octave transposition) | No | Quick listening |

**Example:** A 45 kHz Common Pipistrelle call at 10× time expansion becomes 4.5 kHz — comfortably audible. At 16×, it's 4 octaves down.

## Bat Species Reference (built in)

12 European bat species from 20 kHz (Noctule) to 108 kHz (Lesser Horseshoe):

- Noctule: 20–25 kHz | Leisler's: 25 kHz | Serotine: 25–29 kHz
- Barbastelle: 32 kHz | Nathusius' Pipistrelle: 39 kHz
- Common Pipistrelle: 42–48 kHz | Soprano Pipistrelle: 52–55 kHz
- Daubenton's: 45 kHz | Natterer's: 50 kHz | Brown Long-eared: 45–50 kHz
- Greater Horseshoe: 80 kHz (CF) | Lesser Horseshoe: 108 kHz (CF)

Click any species in the guide to tune the heterodyne oscillator to its peak frequency.

## Requirements

```
numpy >= 2.0
scipy >= 1.10
sounddevice >= 0.4      # PortAudio for live mic input
soundfile >= 0.12       # WAV read/write (libsndfile)
pygame-ce >= 2.5        # Canvas-drawn UI (SDL2 backend)
```

System dependencies (already present on this Jetson):
- `libportaudio2` + `portaudio19-dev` — for sounddevice
- `libsdl2-dev` — for pygame-ce
- `ffmpeg` — optional, for audio format conversion

```bash
pip3 install -r requirements.txt
```

> **Note:** We use `pygame-ce` (community edition) instead of `pygame` because it ships prebuilt ARM64 wheels, while standard pygame requires clang to compile from source on this platform.

### Mouse

All controls are canvas-drawn and clickable:
- **Transport bar**: Play, Pause, Stop, Load WAV, Live Mic buttons
- **Method selector**: Three method buttons + parameter slider
- **FFT size**: Click 512 / 1024 / 2048 / 4096
- **Species guide**: Click a species to tune the heterodyne oscillator
- **Filter panel**: Toggle checkboxes + drag sliders for each filter
- **Record/Export**: Record, Export WAV, Export PNG buttons

## Settings Persistence

Settings are saved to `~/.bat_listener_settings.json` and restored on launch:
- Selected frequency-shift method
- Method parameter value
- FFT size
- All filter states and parameters

## Nyquist Limitation

Standard microphones (44.1/48 kHz sample rate) can only capture up to 22–24 kHz. For real bat detection, you need a 192+ kHz sample rate ultrasonic microphone. The app displays the current Nyquist ceiling on the status bar so you know the frequency limit.

## Comparison with the Original HTML App

| Aspect | Original (HTML/E4B) | This Rewrite (Python) |
|--------|---------------------|----------------------|
| Language | JavaScript (single HTML file) | Python (7 modules) |
| Audio processing | Web Audio API approximations | scipy DSP (real filters) |
| FFT | AnalyserNode.getByteFrequencyData | numpy.fft.rfft + Hann window |
| Heterodyne | Broken (class references undefined `this.processor`) | Working (numpy sine multiplication + butterworth LP) |
| UI rendering | Canvas 2D API | pygame Surface drawing |
| File dialog | Hidden `<input type="file">` | tkinter filedialog |
| Settings | localStorage | JSON file (~/.bat_listener_settings.json) |
| Code quality | 1055 lines, no comments, bugs | ~1600 lines, fully commented, tested |
